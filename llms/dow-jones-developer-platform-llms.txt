# Dow Jones Developer Platform

> Dow Jones publishes The Wall Street Journal, Barron's, MarketWatch and Financial News, and sells
> professional information services — Factiva, Dow Jones Newswires and Dow Jones Risk & Compliance.
> The Developer Platform is the API and feed surface for that content: news search and retrieval,
> economic and IPO calendars, company and executive data, and sanctions/adverse-media screening.
> Generated by API Evangelist on 2026-09-07 from the provider's own documentation and contracts;
> Dow Jones serves no llms.txt of its own (https://developer.dowjones.com/llms.txt returns 404).

Access is entitlement-based. There is no self-serve signup, no published pricing and no free tier —
every route to a credential is a sales conversation. Newswires and Risk & Compliance applications
must additionally pass a Dow Jones technical *and* business certification before serving users.

Base URLs: https://api.dowjones.com (most APIs) and
https://api-thirdparty.riskcenter.dowjones.com (RiskCenter Third Party Platform).
Identity: https://accounts.dowjones.com/oauth2/v1/token — a two-step exchange
(refresh_token -> intermediate token -> jwt-bearer assertion, scope "openid pib") yields the
hour-long bearer token the APIs accept.

## Machine-readable contracts

- [Calendar Live API (OpenAPI 3.0.1, 29 ops)](https://developer.dowjones.com/swagger/calendar_api): economic, corporate and IPO calendar events plus their taxonomies.
- [Newswires Real-Time API (OpenAPI 3.0.1)](https://developer.dowjones.com/swagger/realtime_api): POST /content/realtime/search over DJN taxonomy expressions.
- [Newswires Content API (OpenAPI 3.0.1)](https://developer.dowjones.com/swagger/newswires_content_api): GET /content/{drn} single-article retrieval.
- [Newswires Top Stories API (OpenAPI 3.0.1)](https://developer.dowjones.com/swagger/top_stories_api): entitled content collections and their articles.
- [Company News Radar (OpenAPI 3.0.1)](https://developer.dowjones.com/swagger/company_news_radar): search-realtime content resource.
- [Factiva Content API (Swagger 2.0, 16 ops)](https://developer.dowjones.com/swagger/content_api): search, refs, alerts, newsletters, newsplus collections.
- [Factiva Newsletters API (OpenAPI 3.0.2)](https://developer.dowjones.com/swagger/newsletters_api): JSON:API newsletters and editions.
- [RiskCenter Third Party Platform API 0.1](https://developer.dowjones.com/swagger/third_party_api_0_1): third-party management, beta.
- [RiskCenter Third Party Platform API 0.2](https://developer.dowjones.com/swagger/third_party_api_0_2): third-party management, beta, 22 ops including file upload.
- [Factiva Developer Kit WSDL 3.16](https://developer.factiva.com/3.16/wsdl/FDKObjects.wsdl): SOAP 1.1, nine services, 208 operations (Search, Retrieval, Taxonomy, Membership, Registration, Newsstand, Track, CompanyProfile, MarketData).

## Runtime semantics

- Versioning is by Accept custom media type — `application/vnd.dowjones.dna[.resource][.v_X.Y]+json`;
  the response echoes `X-DJ-Media-Type`. An unsupported version returns **406 Not Acceptable**.
  [Versioning](https://developer.dowjones.com/documents/site-docs-getting_started-versioning-api_versioning)
- Deprecation follows RFC 8594: `Deprecation`, `Sunset` and `Link; rel="deprecation"` headers.
  [Deprecation and sunset](https://developer.dowjones.com/documents/site-docs-getting_started-deprecation_and_sunset_policies)
- Pagination is `offset`/`limit` (or `page[offset]`/`page[limit]`) with a JSON:API `meta` and `links`
  envelope (self, prev, next, first, last).
  [Pagination and caching](https://developer.dowjones.com/documents/site-docs-getting_started-api_essentials-pagination_and_caching)
- Rate limits are published as call frequencies, not headers: Real-Time APIs at most once every
  15 seconds; Top Stories `/content-collections` no more than once every 15 minutes.
  [Certification process](https://developer.dowjones.com/documents/site-docs-newswires_apis-certification_process)
- **No idempotency mechanism exists.** No Idempotency-Key header is documented anywhere. A retried
  create on the RiskCenter Third Party API will create a duplicate.
- **No documented reversal path** for DELETE operations, and no retention window is published.
- Errors are a JSON:API-shaped `errors[]` array; RiskCenter 0.1 also declares RFC 7807 ProblemDetails.

## Event surface

- Factiva Streams — a publish/subscribe surface (not webhooks, no AsyncAPI). Create a filtered
  streaming instance over `https://api.dowjones.com/streams`, then consume JSON messages with a Dow
  Jones streaming client. Version 3.1 (March 2026).
  [Streams](https://developer.dowjones.com/documents/site-docs-factiva_apis-factiva_analytics_apis-factiva_streams_api)
- File-based feeds (Newswires Feeds, Factiva Select, Risk & Compliance watchlists) are delivered over
  SFTP/cloud storage rather than as an API.

- No `/.well-known/security.txt` is served on any Dow Jones host.

## Restrictions an agent must respect

- Dow Jones prohibits using results and content from the Factiva Analytics endpoints to **train or
  refine large language models**.
  [Usage guidelines](https://developer.dowjones.com/documents/site-docs-factiva_apis-factiva_analytics_apis-factiva_usage_guidelines)
- Except for the Content endpoint, results may not be used for viewing of content by downstream users.
- Articles may be stored only for the archive duration named in the contract, then must be purged.
- Applications must carry Dow Jones attribution, branding and copyright notices, and must not place
  third-party advertising against Dow Jones content.
